# Спецификация API и UI

## 1. Конфигурация Firebase
* **Аутентификация:** Firebase Auth (Phone Number Provider).
* **База данных:** Cloud Firestore.

## 2. Модуль аутентификации (Phone Auth)
* **FR-AUTH-01:** Регистрация/Вход по номеру телефона. Firebase отправляет 6-значный код (ограничение Firebase, заменяет 4-значный из ТЗ для MVP без сторонних SMS-шлюзов). TTL управляется Firebase.
* **FR-AUTH-03:** Чекбокс "Согласие с офертой". Состояние чекбокса блокирует кнопку отправки SMS.
* **FR-AUTH-04:** Вход по телефону + SMS. Сессии управляются Firebase Auth (JWT refresh под капотом).
* **FR-AUTH-06:** Смена номера телефона. Требует `PhoneAuthProvider.credential` для нового номера и вызова `updatePhoneNumber`.

## 3. Требования к UI
* **Модальное окно авторизации:** 
  - Шаг 1: Ввод телефона + галочка оферты.
  - Шаг 2: Ввод OTP кода + таймер обратного отсчета (300 сек).
* **Профиль:**
  - Отображение текущего номера телефона.
  - Кнопка "Изменить номер", открывающая флоу верификации нового номера.
* **Обработка состояний:** 
  - Loading: Спиннеры на кнопках при отправке SMS и проверке кода.
  - Error: Информативные уведомления при неверном коде или превышении лимита SMS.
