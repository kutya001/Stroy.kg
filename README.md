# Stroy.kg — Маркетплейс строительных товаров и услуг

Веб-платформа (mobile-first), объединяющая заказчиков строительных товаров и услуг с поставщиками, подрядчиками и застройщиками на рынке Кыргызстана.

## Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Фреймворк | Next.js 15 (App Router) |
| Язык | TypeScript 5.9 (strict) |
| Стилизация | Tailwind CSS 4 |
| UI-иконки | lucide-react |
| Анимации | motion (Framer Motion) |
| Аутентификация | Firebase Auth (Phone/Email) |
| База данных | Cloud Firestore (mock в MVP) |
| Шрифты | Unbounded (заголовки), Golos Text (основной) |

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка проекта
npm run build

# Запуск production
npm start

# Линтинг
npm run lint
```

Приложение откроется на `http://localhost:3000`.

> **Mock-режим:** В MVP все данные хранятся в `lib/mockDb.ts` (in-memory). Реальный Firebase подключается переключением `VERIFICATION_CONFIG.useMock = false`.

## Ролевая модель

Система поддерживает 4 роли пользователей:

| Роль | Код | Описание |
|------|-----|----------|
| Заказчик | `consumer` | Покупатель товаров/услуг. Каталог, заявки, чаты. |
| Поставщик | `supplier` | Продавец. Каталог товаров, обработка заявок, подписки. |
| Застройщик | `developer` | Строительная компания. Функции покупателя + поставщика. |
| Админ | `admin` | Полный доступ. Модерация, переключение ролей для тестирования. |

### Верификация (4 уровня)

| Уровень | Требования | Доступ |
|---------|------------|--------|
| 0 | Регистрация по телефону | Просмотр каталога и ленты |
| 1 | Email + телефон подтверждены | — |
| 2 | ИНН / паспорт | Чаты, заявки, полный функционал |
| 3 | Лицензии / сертификаты | Бейдж «Проверенный», приоритет |

## Номенклатура товаров

4-уровневая иерархия: **Категория → Вид → Группа → Наименование**

- **Категории:** Товар, Услуга
- **Виды:** Инструменты, Материалы, Оборудование, Архитектурные, Строительные, Отделочные, Аренда
- **Групп:** 21 (Бетон, Кирпич, Арматура, Пиломатериалы и др.)
- **Этапы строительства:** 8 (Проектирование → Благоустройство)

Каждая группа имеет свой набор динамических характеристик (Марка, Класс прочности, Диаметр и т.д.).

## Инструкции для Copilot

В `.github/instructions/` хранятся файлы, которые автоматически подключаются к GitHub Copilot Chat при работе с определёнными типами файлов:

| Файл | Применяется к | Назначение |
|------|---------------|-----------|
| `project-conventions.instructions.md` | `**/*.{ts,tsx}` | Стек, архитектура, роли, mock-first, номенклатура |
| `ui-brand.instructions.md` | `**/*.tsx` | Цвета (#E87722/#1E3A5F/#F5C842), mobile-first, русский UI |
| `documentation.instructions.md` | `**/*.md` | Русский язык, DevHistory, формат документов |
| `build-verification.instructions.md` | On-demand | Проверка сборки после изменений кода |
