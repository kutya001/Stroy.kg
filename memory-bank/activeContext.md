# Текущий контекст разработки

**Над чем ведется работа:**
Реализация модуля аутентификации по номеру телефона (FR-AUTH-01, FR-AUTH-03, FR-AUTH-04, FR-AUTH-06) с использованием Firebase Phone Auth.

**Текущие задачи:**
1. Замена Google Auth на Phone Auth в `AuthProvider.tsx`.
2. Создание модального окна для ввода телефона и SMS-кода.
3. Добавление чекбокса согласия с офертой (блокировка кнопки).
4. Реализация таймера 300 сек на повторную отправку SMS.
5. Интеграция функционала смены номера телефона в профиле пользователя.

**Проблемы и ограничения:**
- Firebase Phone Auth отправляет 6-значный код, а не 4-значный (ограничение платформы).
- Требуется настройка `RecaptchaVerifier` для защиты от спама.
