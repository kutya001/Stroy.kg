Версия проекта - 1.0.0.0

**Запрос:**
Fix the following errors: Uncaught TypeError: Converting circular structure to JSON --> starting at object with constructor 'HTMLElement' | property '__reactFiber$kek5b0rtgp' -> object with constructor 'FiberNode' --- property 'stateNode' closes the circle

**Анализ:**
Ошибка "Converting circular structure to JSON", начинающаяся с `HTMLElement`, обычно возникает в Next.js 15 / React 19, когда DOM-элемент или синтетическое событие React (SyntheticEvent) случайно передается в функцию, которая пытается его сериализовать (например, в Server Action или при перехвате отправки формы без явно заданного обработчика). В компоненте `app/create/page.tsx` присутствовал тег `<form>` без атрибутов `action` или `onSubmit`. При нажатии клавиши Enter внутри полей ввода браузер инициировал отправку формы, которую Next.js пытался перехватить и обработать по умолчанию, что приводило к попытке сериализации события и возникновению циклической ошибки.

**Формализованное требование после Анализа:**
Устранить причину непреднамеренной отправки формы и сериализации DOM-событий в компоненте создания заявки.

**Требуется изменить/разработать:**
Заменить тег `<form>` на `<div>` в компоненте `app/create/page.tsx`, так как на данном этапе форма используется исключительно для визуальной разметки и не имеет логики отправки данных на сервер.

**Фактически внесенные изменение:**
- В файле `app/create/page.tsx` тег `<form className="space-y-8">` заменен на `<div className="space-y-8">`.
- Закрывающий тег `</form>` заменен на `</div>`.

**Следующие шаги:**
- Реализация логики работы с данными (Firebase) для сохранения заявок.
- Настройка клиентской валидации и обработки состояний для формы создания заявки.
- Интеграция аутентификации пользователей.
