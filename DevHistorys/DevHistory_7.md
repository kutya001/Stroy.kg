Название файла - DevHistory_7.md

Версия проекта - 1.0.5.0

**Запрос:**
Доработай:
- Чаты
- Окно уведомлений
- Окно поставщиков , добавление номенклатуры
- Разграничение в доступах к экранам и функционалам между Покупателями и Продавцами

**Анализ:**
Необходимо реализовать ролевую модель (RBAC) для разделения интерфейса между Покупателями (consumer) и Продавцами (supplier). Также требуется добавить функционал уведомлений, чатов и страницу добавления товаров для поставщиков.

**Формализованное требование после Анализа:**
1. **RBAC (Разграничение доступа):**
   - Главная страница (Лента): Покупатели видят кнопки "Купить материалы" и "Создать заявку". Поставщики видят "Добавить товар", "Мои товары" и приветствие "Добро пожаловать, Поставщик!".
   - Навигация (Header и Mobile Nav): Кнопка "Создать заявку" меняется на "Добавить товар" для поставщиков.
   - Каталог: Поставщики видят кнопку "Добавить товар" в панели фильтров.
2. **Окно уведомлений:**
   - Добавить выпадающий список уведомлений в `Header.tsx` (по клику на иконку колокольчика).
   - Интегрировать моковые уведомления из `mockDb.ts`.
3. **Окно поставщиков (Добавление номенклатуры):**
   - Создать страницу `/add-product` с формой добавления товара/услуги (доступна только поставщикам).
   - Интегрировать сохранение товара в моковую базу данных (`createMockProduct`).
4. **Чаты:**
   - Переписать страницу `/chats` для отображения списка диалогов из моковой базы данных (`getMockChats`).
   - Добавить индикацию непрочитанных сообщений.

**Требуется изменить/разработать:**
- `lib/mockDb.ts` (добавление моковых чатов, уведомлений, функции создания товара)
- `components/Header.tsx` (уведомления, RBAC навигация)
- `components/Navigation.tsx` (RBAC для мобильной навигации)
- `app/page.tsx` (RBAC для ленты)
- `app/catalog/page.tsx` (RBAC для каталога)
- `app/add-product/page.tsx` (новая страница добавления товара)
- `app/chats/page.tsx` (интеграция моковых чатов)

**Фактически внесенные изменение:**
- В `mockDb.ts` добавлены массивы `mockNotifications` и `mockChats`, а также функции для работы с ними (`getMockNotifications`, `markNotificationAsRead`, `getMockChats`, `createMockProduct`).
- В `Header.tsx` реализовано выпадающее окно уведомлений с возможностью отметки "прочитано". Навигация адаптируется под роль пользователя.
- В `Navigation.tsx` центральная кнопка меняется с "Заявки" (PlusCircle) на "Добавить" (PackagePlus) в зависимости от роли.
- Главная страница (`app/page.tsx`) теперь отображает разный набор быстрых действий для покупателей и поставщиков.
- Создана страница `/add-product`, содержащая форму с выбором категории, вводом цены, описания и единиц измерения. Форма защищена проверкой роли (только `supplier`).
- Страница `/chats` переписана: теперь она получает список чатов из моковой БД, корректно отображает собеседника (в зависимости от того, кто авторизован) и показывает счетчик непрочитанных сообщений.

**Следующие шаги:**
- Реализация детальной страницы чата (переписка).
- Редактирование профиля пользователя.
- Фильтрация каталога и ленты по категориям.
