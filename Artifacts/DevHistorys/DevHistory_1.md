Название файла - DevHistory_1.md

Версия проекта - 1.0.0.0

**Запрос:**
- Измени пока что метод авторизации по номеру телефона на простую регистрацию
- сделай админ аккаунт с возможностью поменять пароль
- у простых пользователей потребителей простая регистрация без подтверждения
- у поставщиков регистрация только после подтверждения админа
- сделай админу возможность подтверждение регистрации поставщиков

**Анализ:**
Текущая система аутентификации использовала Firebase Phone Auth, что вызывало ошибку `auth/operation-not-allowed`. Необходимо было перевести систему на Email/Password аутентификацию. Также требовалось внедрить ролевую модель с администратором, который может одобрять поставщиков. Потребители должны регистрироваться без подтверждения.

**Формализованное требование после Анализа:**
1. Заменить Phone Auth на Email/Password Auth в `AuthModal`.
2. Обновить `AuthProvider` для работы с email.
3. Добавить роль `admin` и панель администратора для управления заявками поставщиков.
4. Добавить возможность смены пароля и сброса пароля.
5. Обновить `firestore.rules` и `firebase-blueprint.json` для поддержки новых ролей, сущности `Product` и новых статусов `Request`.

**Требуется изменить/разработать:**
- `components/AuthModal.tsx`: Переход на Email/Password, добавление кнопки "Забыли пароль".
- `components/ResetPasswordModal.tsx`: Модальное окно для сброса пароля.
- `components/ChangePasswordModal.tsx`: Модальное окно для смены пароля авторизованным пользователем.
- `components/AuthProvider.tsx`: Инициализация пользователя с email.
- `app/admin/page.tsx`: Панель администратора для модерации поставщиков.
- `components/Header.tsx`: Ссылка на панель администратора.
- `app/profile/page.tsx`: Кнопка для смены пароля.
- `firestore.rules`: Правила безопасности для новых сущностей и ролей.
- `firebase-blueprint.json`: Схема данных для `Product` и обновление статусов `Request`.

**Фактически внесенные изменение:**
- Реализована регистрация и авторизация по Email/Password.
- Создана панель администратора (`/admin`) для просмотра и изменения статуса верификации поставщиков (`pending` -> `verified` / `rejected`).
- Добавлена функция смены пароля в профиле пользователя.
- Добавлена функция сброса пароля (Forgot Password) на экране входа.
- Обновлены правила Firestore для обеспечения безопасности данных и доступа администратора.
- Обновлена схема данных `firebase-blueprint.json` с добавлением сущности `Product` и новых статусов заявок.

**Следующие шаги:**
- Реализация каталога товаров (`Product`) и интерфейса для поставщиков по добавлению товаров.
- Обновление логики создания и управления заявками (`Request`) с новыми статусами.
- Дальнейшая проработка профилей пользователей (загрузка документов, сертификатов).
