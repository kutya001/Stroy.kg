Версия проекта - 1.0.3.0

**Запрос:**
Удали полностью всю логику связанную с firebase, пока что сайт будет чисто как макет, без привязки к базе данных, с иметируй работу базы данных с демонстративными данными. Сделай фиктивную регистрацию бе проверки пароли или номера телефона. Проверь еще раз пункт аутентификации Регистрация по номеру телефона СМС.

**Анализ:**
Проект временно переводится в режим макета (MVP без бэкенда). Необходимо отключить Firebase, чтобы избежать ошибок авторизации и проблем с подключением. Вся работа с данными (пользователи, профили, статусы верификации) должна быть переведена на моковые данные (in-memory / localStorage). Авторизация должна стать фиктивной: вход по любому номеру телефона без реальной отправки СМС, а для администратора — вход по заранее заданному номеру и паролю.

**Формализованное требование после Анализа:**
1. Удалить инициализацию и использование Firebase Auth/Firestore.
2. Создать локальную мок-базу данных (`lib/mockDb.ts`) для хранения пользователей.
3. Переписать `AuthProvider` для работы с мок-базой.
4. Обновить `AuthModal` для фиктивного прохождения шагов (ввод телефона -> любой фиктивный код -> вход/регистрация).
5. Добавить хардкод-логин для администратора (номер + пароль).

**Требуется изменить/разработать:**
- `lib/mockDb.ts` (создать)
- `components/AuthProvider.tsx` (изменить)
- `components/AuthModal.tsx` (изменить)
- `components/ChangePasswordModal.tsx` (изменить)
- `app/admin/page.tsx` (изменить)

- Создан файл `lib/mockDb.ts` с начальными данными (включая админа `+996555000000` с паролем `admin`).
