# DevHistory 13 — Редактирование заявок (v1.7.0.0)

**Дата:** 28 марта 2026  
**Версия:** 1.7.0.0  

## Описание

Добавлена возможность редактирования созданных заявок (только со статусом «Открыта»). Покупатель может изменить все поля заявки через ту же форму создания.

## Внесённые изменения

### 1. Функция `updateMockRequest` в `lib/mockDb.ts`
- Добавлена CRUD-функция `updateMockRequest(id, data)` для обновления заявки по ID
- Редактирование разрешено только для заявок со статусом `OPEN`
- Принимает `Partial<MockRequest>`, обновляет поля через spread

### 2. Режим редактирования на странице создания (`app/create/page.tsx`)
- Поддержка query-параметра `?editId=req-123` для входа в режим редактирования
- Форма предзаполняется данными существующей заявки (название, категория, объём, бюджет, описание, уточнения номенклатуры)
- Заголовок формы и текст кнопки меняются: «Редактировать заявку» / «Сохранить изменения»
- Кнопка «Отменить редактирование» для выхода из режима без сохранения
- После сохранения — сброс формы, переход на вкладку «Мои заявки»

### 3. Кнопка «Редактировать» в списке «Мои заявки» (`app/create/page.tsx`)
- Отображается только для заявок со статусом `OPEN`
- Иконка `Pencil` + текст «Редактировать»
- Ведёт на `/create?editId={id}`

### 4. Кнопка «Редактировать» на странице деталей заявки (`app/request/[id]/page.tsx`)
- Отображается только автору заявки при статусе `OPEN`
- Расположена в заголовке рядом с названием заявки
- Стилизована под брендовые цвета (primary/10 фон)

## Затронутые файлы

| Файл | Изменение |
|------|-----------|
| `lib/mockDb.ts` | Добавлена `updateMockRequest()` |
| `app/create/page.tsx` | Режим редактирования, предзаполнение, кнопка в списке |
| `app/request/[id]/page.tsx` | Кнопка «Редактировать» в шапке заявки |

## Ограничения

- Редактирование доступно только для заявок со статусом `OPEN` (до назначения поставщика)
- Mock-реализация (in-memory), при переходе на Supabase потребуется update через `lib/queries.ts`
