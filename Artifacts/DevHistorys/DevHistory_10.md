Название файла - DevHistory_2.md

Версия проекта - 1.1.0.0

**Запрос:**
- Карточка товара — при нажатии чтобы можно было открыть и просмотреть карточку товара
- Сделай верификацию пока что фиктивной, чтобы её можно было легко включить
- Сделай Админский доступ, в котором можно переключаться между Ролями
- Лента — должна быть лента товаров и услуг если это Покупатель, если это продавец то Лента Заявок

**Анализ:**
Базовый MVP был полностью реализован: авторизация, каталог, создание заявок, чат, профиль, админ-панель. Однако карточки товаров в каталоге не были кликабельными, верификация не имела интерактивного flow, админ не мог тестировать UX других ролей, а лента на главной странице показывала заявки для всех пользователей без разделения по ролям. Требовалось расширить функциональность по четырём направлениям.

**Формализованное требование после Анализа:**
1. Создать динамическую страницу `/product/[id]` с полным описанием товара, характеристиками, информацией о поставщике и другими товарами поставщика. Обернуть карточки каталога в ссылки на эту страницу.
2. Реализовать систему фиктивной верификации с конфигурацией `VERIFICATION_CONFIG` (`useMock: true`), набором mock-функций и интерактивным модальным окном в профиле с 4 шагами (email, код, ИНН, лицензия). При переключении `useMock: false` — заглушки для реального API.
3. Добавить в `AuthProvider` механизм `adminViewAs` для просмотра интерфейса от лица другой роли. Добавить UI переключателя ролей в админ-панель и индикатор-баннер в Header.
4. Переписать главную страницу (`/`) — покупатели видят ленту товаров/услуг, поставщики видят ленту заявок. Фильтры (Все/Товары/Услуги) работают для обеих лент.

**Требуется изменить/разработать:**
- `lib/mockDb.ts`: Добавить `getProductById`, `VERIFICATION_CONFIG`, 6 async mock-функций верификации.
- `app/product/[id]/page.tsx`: Новая динамическая страница карточки товара.
- `app/catalog/page.tsx`: Обернуть карточки товаров в `<Link>` на `/product/[id]`.
- `app/profile/page.tsx`: Добавить интерактивное модальное окно верификации с 4 шагами.
- `components/AuthProvider.tsx`: Добавить `adminViewAs`, `isAdminMode`, `setAdminViewAs`, `effectiveUserData`.
- `app/admin/page.tsx`: Добавить UI переключателя ролей (4 кнопки).
- `components/Header.tsx`: Добавить amber-баннер при просмотре от лица другой роли.
- `app/page.tsx`: Переписать ленту — товары для покупателей, заявки для поставщиков.

**Фактически внесенные изменения:**

1. **Карточка товара (`app/product/[id]/page.tsx`)**:
   - Создана динамическая страница с хлебными крошками, крупным изображением с бейджами (Продвигается/Топ/Новинка), секцией описания, таблицей характеристик, боковой панелью с ценой и кнопками действий (Отправить запрос/Написать продавцу/Позвонить), карточкой поставщика, блоком «Другие товары поставщика».
   - Добавлена функция `getProductById` в `mockDb.ts`.
   - Карточки в каталоге (`app/catalog/page.tsx`) обёрнуты в `<Link href={/product/${id}}>`, кнопки действий вынесены за пределы ссылки для избежания вложенных `<a>`.

2. **Фиктивная верификация**:
   - Добавлен `VERIFICATION_CONFIG = { useMock: true, mockOtpCode: '1234', mockDelay: 800 }` в `mockDb.ts`.
   - Реализованы 6 async mock-функций: `sendPhoneOtp`, `verifyPhoneOtp`, `sendEmailVerification`, `verifyEmail`, `submitInnVerification`, `submitLicenseVerification` — каждая проверяет `useMock` флаг и содержит TODO-заглушки для реального API.
   - В `app/profile/page.tsx` добавлено модальное окно верификации с 4 шагами: ввод email → подтверждение кода → ввод ИНН → загрузка лицензии. Каждый шаг показывает подсказку «ТЕСТОВЫЙ РЕЖИМ» с mock-кодом. Карточки прогресса верификации получили кнопки «Подтвердить»/«Заполнить».

3. **Админский доступ с переключением ролей**:
   - В `AuthProvider.tsx` добавлены: состояние `adminViewAs`, вычисляемое свойство `isAdminMode`, функция `setAdminViewAs`, объект `effectiveUserData`, который подменяет `userData.role` при просмотре от другой роли. `canAccessChat`/`canAccessRequests` используют `effectiveUserData`.
   - В `app/admin/page.tsx` добавлена секция «Просмотр как роль» с 4 кнопками (Администратор/Покупатель/Поставщик/Застройщик) с цветной индикацией активной роли и предупреждением при просмотре.
   - В `components/Header.tsx` добавлен sticky amber-баннер с иконкой Eye и кнопкой закрытия (X), показывающий «Просмотр как: [Роль]» при активном переключении.

4. **Лента по ролям (`app/page.tsx`)**:
   - Покупатели видят grid товаров/услуг из `getAllMockProducts(true)` — карточки с изображением, бейджами (РЕКОМЕНДУЕМ/НОВИНКА), рейтингом, информацией о поставщике, ценой, ссылкой на `/product/[id]`. Товары отсортированы: продвигаемые первыми, затем по дате.
   - Поставщики/Застройщики видят ленту заявок из `getAllMockRequests()` — карточки с категорией, объёмом, бюджетом, кнопкой «Откликнуться».
   - Фильтры (Все/Товары/Услуги) работают для обеих лент — фильтрация `nomenclatureCategory` для товаров и `category` для заявок.
   - Пустое состояние при отсутствии совпадений по фильтру.
