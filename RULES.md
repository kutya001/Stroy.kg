# Tech Stack
- Фреймворк: Next.js 15 (App Router)
- Язык: TypeScript (строгая типизация обязательна)
- Стилизация: Tailwind CSS
- База данных и Аутентификация: Firebase (Firestore, Firebase Auth)
- Иконки: lucide-react

# Architecture Rules
- Использовать только функциональные компоненты и хуки. Никаких классовых компонентов.
- Разделять логику и UI: контексты и провайдеры (например, `AuthProvider.tsx`) выносить в `components/` или `lib/`.
- Все интерфейсы TypeScript хранить рядом с логикой или в выделенных файлах типов.
- Взаимодействие с Firebase инкапсулировать в провайдерах или кастомных хуках.
- Использовать `use client` только там, где необходима интерактивность (хуки состояния, обработчики событий, Firebase Auth).

# AI Guidelines
- Не использовать устаревшие библиотеки.
- Перед написанием кода проверять `SPEC.md` и `memory-bank/systemArchitecture.md`.
- Строго следовать требованиям безопасности Firestore (Firestore Rules).
- При реализации UI учитывать мобильные устройства (Mobile First).
